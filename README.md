# ElectroQuest Pro — Segunda Evaluación

Aplicación web de entrenamiento para **Electrotecnia** (nivel de parcial real).

## Contenido
- **Leyes de Kirchhoff** (nudos y mallas) con rigor teórico
- Convención de signos y interpretación de corrientes negativas
- **Ejercicio completo** de dos baterías en paralelo + lámpara (con diagrama SVG)
- **Motores** de CC y CA (principio físico, colector de delgas, jaula de ardilla, bobina de arranque)
- Repaso selectivo de la 1ª evaluación

## Cómo usarla
1. Entrá al repositorio: https://github.com/donp06343-droid/ElectroQuest-Pro
2. Abrí el archivo `index.html`
3. Hacé clic en **Raw** o descargalo y abrilo en el navegador

### Opción GitHub Pages (recomendado)
- Andá a **Settings → Pages**
- Source: Deploy from a branch → `main` → Save
- En unos segundos tendrás el link público:
  **https://donp06343-droid.github.io/ElectroQuest-Pro/**

## Modos
- **Modo Examen**: 18 preguntas, 3 vidas, sin pistas hasta responder
- **Modo Estudio**: mismas preguntas, explicaciones completas, sin límite de vidas
